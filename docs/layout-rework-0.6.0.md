# 首页与牌桌布局修复

- 取消整张 1280×853 画布的横纵缩放。桌面背景铺满屏幕，交互区域单独保留设备安全区。
- 战队准入提示归入首页左栏，避免成为第三个网格单元；实时牌桌固定在右栏。
- 两侧手牌、碰杠整体朝向各自座位；杠牌四张按同一基线排列，三组及以上碰杠采用两排。
- 花牌使用独立区域，与手牌轨道、弃牌、头像保持间距；对家花牌在右上角按四张一排显示。
- 托管、碰杠胡和听牌提示使用底部操作栏；听牌详情由玩家主动点开。
- 弃牌尺寸与槽位仅取决于窗口尺寸；出牌、换行与显示操作按钮不会改变牌的尺寸。

验证以 iPhone 17 Pro 模拟器和浏览器设备安全区为准，覆盖普通牌局、20 花、32 张弃牌及四组杠牌。
