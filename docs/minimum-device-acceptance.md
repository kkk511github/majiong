# 最低支持设备验收门禁

2026-09-27 用户明确要求本批可暂缓最低系统真机验收。本批仍执行浏览器、模拟能力缺失、代码与构建验证；下列真机项维持待验证，不伪造通过结论。

不能以现代WebKit模拟移除API代替旧系统真机结论。当前最低声明维持iOS15 / Android API24，不降低版本。

每次正式发布记录安装包SHA256、设备型号、系统及WebView版本、执行人、时间、结果和脱敏诊断编号。

| 设备要求 | 状态 |
| --- | --- |
| iPhone8或同级设备，iOS15.0–15.3 | 待提供可用真机 |
| Android7/8，低内存设备及其旧WebView | 待提供可用真机 |
| 较新iOS与安卓对照设备 | 待本批功能完成后验收 |

必须检查：覆盖安装/登录、断网及切后台恢复、两把真实流程、准备倒计时、滑动与双击、碰/杠/胡/过、补花/暗杠/补杠、即时扣分、听牌提示、结算/账单解释/回放、日志主动上传及后台采集。确认低内存/图形恢复不丢操作、不重复出牌；确认无网络时有明确状态，不假装操作成功。

未拿到设备和结果前，验收保持“待验证”，不得在发布说明中写“最低系统真机通过”。
