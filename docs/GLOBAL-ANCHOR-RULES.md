# 全球独钓黄色架牌与外包

更新日期：2026-09-22。外包沿用现有进园子规则：普通局50分，比下胡100分，桌外单独记分，不扣桌内余额。

## 建立条件

四组均允许碰、明杠或暗杠。服务器记下实际完成第四组的碰杠操作；碰后剩两张，杠后先正常收杠分并补牌至两张。随后首次出牌、剩一张时，才记录本次实际打出的物理牌及私有单钓牌种类。杠后连续补花不影响这个待架牌状态。已触发三嘴或三清即时外包时直接结束，不再补牌或建立架牌。

只有这张实际打出的牌变黄。其他同点数牌不变黄；若该牌被别人碰、杠收走，黄色跟随该物理牌进入明牌组。缺少完成第四组的操作凭据，不能仅凭“剩一张手牌”建立架牌；后续补杠不会重新建立已取消的架牌。

## 外包条件

黄色只是提示，不禁出牌。同花色且点数差不超过2，包括架牌本身；风牌沿用原规则，四风互相处于范围内。范围不跨花色、1和9不循环。

其他玩家打出范围内的牌、架牌方确实能胡且实际选择胡牌后，结算引擎才应用外包。过牌、不成胡、自摸不收这项外包。零桌内余额玩家不能被胡、三嘴/三清/抢杠等结算优先顺序继续沿用现有规则。

## 保持与取消

摸牌本身不取消。摸切，或留下同点数的另一张物理牌，听口没有变化，标记继续有效。

出牌后留下的单钓牌种类改变，服务器立即删除架牌对象，发给四个座位的黄色列表也立即变空。后来换回原听口不会重新建立架牌。换把重置全部标记。

公开快照只含架牌的物理编号和原出牌座位，不发送其他玩家单钓什么牌、原听口或待架牌内部状态。回放记录每一步公开标记；断线和进程重启读取同一份持久化状态。

旧快照若只有“架牌点数”而没有操作来源和物理编号，不能证明合法成立，因此新逻辑不沿用其外包责任，也不猜测补黄。已有完整的第四碰状态与新的第四组杠牌状态均可恢复。

## 复现页

本地地址：http://127.0.0.1:5180/tests/previews/global-anchor.html

1. 原例：碰第四嘴，打6条、留5万，6条变黄。4～8条属于风险范围，但甲实际听5万，因此打5条不能被甲胡，也不收外包；5万可以胡，但不在6条范围内，是普通胡牌。
2. 实际外包：碰第四嘴，打6条、留5条；乙打5条后甲可选择胡或过。普通局胡收桌外50分，比下胡收100分，过不收。
3. 改支：按原例架牌后，走完其他三家出牌，甲摸3筒。甲打5万、留3筒的同一步去黄并清除责任。
4. 暗杠架牌：三碰后暗杠1筒、补6条，再打6条、留5万；6条变黄。杠费仍按原规则即时收分；实际单钓5万不在6条风险范围内，不能因此收架牌外包。
