# 金陵麻将 0.7.25 / build 62

本版优化 iOS、Android 与网页共用的真实 Cocos 牌桌，并接入安装包版本更新。

- 倒计时只更新数字，复用 HUD、花槽、阴影和来源标记；同帧状态合并后绘制。飞牌立即起步、平滑归位，摸牌起点跟随缩短的手牌。拖牌拒绝、断网与超时恢复保留，暗杠无关牌保持静止。
- 碰、明杠、暗杠、补杠和补花统一为局部玉绿底、暖金字。去除原本字下方的菱形装饰；同座只保留一条提示，不挡余牌余花。
- 初始发牌中的补花不再排入报牌语音队列，避免开局动画结束后才喊补花；真正摸花、杠后补花和原点击牌声音保持。
- 首页使用完整秦淮全景背景，覆盖视口，身份与管理入口保持原有权限。生成方式、原图及完整提示词见 [设计记录](design/native-refresh-v3-prompts.md)。
- “我的”顶部与大厅设置新增检查更新。大厅可提示新版，未点击不下载、不打断对局。Android 下载后校验文件与当前应用签名，进入系统安装确认；iOS 前往固定安装页。进度、取消、安装来源授权、错误重查均可见，打开安装器不等同于安装成功。
- 固定分发页改为金陵麻将专用品牌；微信/QQ保留用户确认的白底右上角菜单引导。后台同平台上传仍原子替换，链接不变。

首次启用更新能力，需要先安装本次含原生插件的安装包；旧版本无法凭空获得原生更新功能。后续 Android 新包须沿用原正式签名并递增 build；iOS 签名后应保留应用标识与版本信息。
