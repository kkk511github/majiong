## 材质和实现

全部共用暖白牌面、浅刻同心圈和玉绿色牌底。六、九筒的生成稿作为圈纹源，一筒使用新花纹原稿；从原稿提取着色刻纹后，以精确坐标排布到实体牌面的 UV 中，再使用既有立体牌体和摄像机烘焙各视角。其他数字的设计图已经逐张生成，生产圈纹共用可以避免不同图片产生圈径或线宽漂移。

坐标及直径见 `production-layouts.json`。比例以实体正面为基准，已经补偿 UV 映射比例。材质沿用现有牌体，不改变桌面、花槽、弃牌和碰杠布局。仅更新牌面 kind 9–17，不改变万、条、字、花牌及背面。

## 可重现构建

1. `node cocos-table/tools/prepare-dots-v3.mjs` 生成九张带透明底的刻纹。
2. Blender 调用 `cocos-table/tools/render_tiles.py`，参数 `--kinds 9,10,11,12,13,14,15,16,17`，渲染既有十三种正面视角。
3. `node cocos-table/tools/merge-tile-faces.mjs <烘焙目录> 9,10,11,12,13,14,15,16,17` 替换原图集对应格子；保留原有裁切尺寸和锚点；轮廓偏差超出容差时拒绝写入。
4. `node cocos-table/tools/export-web-tiles.mjs` 同步 React 的手牌、听牌和结算资源。
5. `npm run build:cocos` 更新安卓/iOS共用的 Cocos 网页运行资源。

九张 `dots-N-v3-preview.png` 是设计原稿；游戏内效果以离线牌体渲染为准。生成提示词保存在本目录的两份提示词文件中。

## 验证结果

九张筒牌共十三种正面视角已经替换。已与替换前备份逐像素比对，其他牌面和背面未变化，图集坐标及尺寸未变化。Cocos 共用资源构建、TypeScript 检查通过，已在本地牌桌预览确认。现有已安装的 APK / IPA 需下次打包后更新。
