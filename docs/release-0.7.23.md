# 金陵麻将 0.7.23 / build 60

## 规则和显示

只有三组明碰后再碰第四组、随后出牌剩一张才建立架牌。黄色对应形成时实际打出的那张牌，风险范围为同花色前后两张；真正选择胡牌时才按现有规则记外包，进园子普通局50分、比下胡100分。主动换听时服务器清除外包状态，四家界面和回放同步取消黄色。暗杠或直杠形成的独钓不建立此架牌关系。完整规则见 GLOBAL-ANCHOR-RULES.md。

包含之前已完成的网页声音路径、首把开局动画和画布恢复修复；碰杠、四风等即时扣分显示在对应玩家门前。旧版没有第四碰操作凭据的存档不推测重建架牌，已有战绩不重新结算。
