# 0.5.4 结算与下一局

普通注册账号的首页和大厅不显示开桌入口，仅管理员和拥有独立开桌授权的账号显示。后端每次开桌都重新验证账号权限，撤权立即关闭入口和已展开的设置。此次完整回归再次验证了这条用户要求，没有扩大普通玩家权限。

结算表的昵称下直接显示各自的已准备、未准备、已离线、托管就绪或待确认继续状态。下方说明正在等待哪位牌友；所有人就绪仍会等完本桌设置的结算展示时间。前端与后端共用准备资格判断，离线玩家勾选准备不会造成“全员就绪但不能开局”的错误提示。离线可开局等自定义设置仍按原配置执行。

慢网准备提交时禁用重复点击；连接断开时改为等待重新连接并将四家状态标记待同步。自动续桌已返回大厅后，上一条离桌命令的迟到错误不再覆盖成功反馈。568×320 横屏压缩行间留白，四家战绩、关闭和继续按钮完整可见。

连续运行还发现默认联机托管会跳过合法胡牌。已修正为优先执行服务端判定合法的自摸或点炮胡牌；其他自动过牌和摸切策略保持。四种真实 WebSocket 用例（手动/超时进入托管 × 自摸/点炮）先在旧代码全部复现失败，修正后验证。此修改不改变洗牌、胡牌资格、分值或用户手动操作。

## 验证

- 最初 127 项逻辑/服务测试全部通过，包括准备资格、真实 WebSocket 离线阻止下一局及恢复连接后开局、迟到错误隔离。
- 102 项界面回归全部通过，包含普通账号入口、授权/撤权、三种尺寸结算、慢网准备及重连。此后修正的托管合法胡牌优先级另由服务端专项与全量逻辑回归验证，八局连续运行使用修正前已启动的服务进程，不能将其说成覆盖了新增自动胡分支。
- 568×320 额外检查每一行底部都在结算内容区内，避免仅检测中心命中而漏掉第四行局部遮挡。
- 四个真实账号八局联机共 717 秒通过，刷新重连、10 秒结算、返回大厅与空桌续开正常，管理员仅一条最终战绩；练习四局 181 秒通过，四局均实际胡牌。八局运行进程早于自动胡修复，八局均流局；修正后的托管合法胡由四项真实服务测试覆盖，全部逻辑/服务测试 131 项通过。
- iOS build 14 在模拟器通过命令安装启动；Ad Hoc 严格签名和资源校验通过，描述文件包含已登记 iPhone。安卓 APK 与上一版测试签名一致，包内资源对应本次构建。
