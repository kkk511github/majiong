# 后台会员对局查询

更新：已于2026-09-26部署服务端及后台，见 [部署记录](deployment-diagnostics-20260926.md)。下文保留实现时的验证说明。

入口：管理后台 → 会员对局。输入数字会员ID，选择开始与结束日期后查询。

- 单日：开始、结束日期相同；支持“设为同一天 / 今天 / 近7天”。
- 区间：包含首尾日期，按北京时间，单次最多366天。
- 汇总：范围内总桌数、逐日桌数；点击某日可下钻。
- 列表：结束时间倒序，每页20桌，分页不改变总数。
- 详情：房号、牌局ID、同桌玩家、整桌结算、每把结果和查询会员本把变化。

## 统计口径

查询 `match_records`，按整桌结束时间归属日期。每个 `game_id` 取最新结束快照，只计一桌，不将8把计为8桌；同房号的不同牌局分别计算。包括提前结束、体验桌，不按会员战队过滤。尚未结束的牌桌不计入。详情的整桌记分复用现有结算逻辑，每把变化为原始分，不能与整桌除数、桌费混算。

会员ID由 `account_numbers` 精确查找。删除登录账号不会抹去保留的历史对局；无此会员ID与该范围内0桌分别提示。

## 接口及权限

- `GET /api/control/member-games?memberId=100022&from=2026-09-18&to=2026-09-25&page=1`
- `GET /api/control/member-games/:gameId?memberId=100022`

每次请求使用现有后台会话鉴权，仅管理员可查询。详情再次验证所选会员属于该桌；不允许通过此接口修改战绩。建立 `(game_id,at DESC,id DESC)` 索引以避免去重查询重复全表扫描。

## 验证与发布

新增接口测试覆盖管理员权限、日期边界、去重、分页、空结果、已删除会员、会员与牌桌对应关系和参数校验。浏览器测试覆盖查询、分页、详情、按日下钻、错误提示和390px窄屏。

本次仅修改服务端和管理后台，不要求重新打包APK/IPA。当前为本地完成，需部署服务端及后台静态资源后线上生效；不包含自动部署或发布安装包。
