# 南京麻将当前规则全面核查

核查日期：2026年9月18日。对象为当前默认进园子 B档 `nj-garden-b-v3`，以用户已确认规则和当前完整规则为依据。网上规则作为差异参考，不直接替换定制玩法。

## 确认的问题与修复

### 1. 起手花杠使两家归零，漏保米并继续补花

触发条件：开始一把后，起手发到的花牌或补花集齐花杠，其即时付款让第二家桌内归零。

独立完整144张牌墙复现：甲8、乙0、丙6、丁346，甲花杠。丙付6、丁付10后，甲24、乙0、丙0、丁336。旧代码就这样结束，漏掉丁向甲补76的保米；并且在结束前还继续补花。

修复后立即按本次花杠者保米，最终甲100、乙0、丙0、丁260，停止后续补花和收付。未处理的花牌保留在原手牌中，144张牌守恒。覆盖庄家和闲家、普通及比下胡、健康余额继续补齐的6个新增回归场景。

### 2. 管理员积分对历史导入练习记录的过滤

正常单人练习只在本地运行，不向服务器提交计分。Telegram日结、周结已排除练习桌。审计用内存数据库模拟人工导入的练习历史，发现管理员积分汇总/CSV仍可能将其计入。已补充采集、历史迁移、汇总和首次桌费判断的练习过滤，不删除历史记录。

| --- | --- |

| 比下胡胡牌分 | 先汇总全部胡牌计分项目，最后乘本把倍率一次；明细的“比下胡”行是新增分，不是再计一遍最终总分 |
| 明杠、补杠、暗杠、花杠 | 普通10/10/各5/各10；默认比下胡20/20/各10/各20。即时收分与胡牌软花分开 |
| 自己打齐同种四张 | 普通向三家各付5，比下胡各付10；已被碰走的牌仍算本人出牌记录 |
| 四连风、首轮四家跟风 | 当前固定每家5，不随比下胡翻倍；是现有口径，和部分网上版本不同 |

| 三嘴、三清、全球架牌承包 | 责任优先级独立牌例通过；桌外普通50、比下胡100，不扣桌内余额 |
| 一炮多响 | 余额不足按应得比例分配，整数余数确定分配；未发现凭结算顺序多扣余额 |
| 两家归零、保米 | 胡牌/杠收分终局保米到100；纯罚分不保米；起手花杠遗漏已修复 |
| 连庄、轮庄、接庄 | 庄家胡（含多响包含庄家）或流局连庄；其余顺移下一位。下一位胡且轮到他为接庄比 |
| 下一把倍率 | 默认触发为2倍，连续触发仍2倍；大胡等只决定比下胡，不能额外连庄 |

| 每把与最终结算 | 每把桌内变化+桌外变化；整桌（余额−100＋外部累计）按保存的记分倍率换算，90起分与100基准差额只扣一次 |
| 日结、周结 | 日结原始净分÷2；周结完成桌数×3；20栏为0；周期最终战队归属；正常练习不统计 |
| 续桌 | 到把数或提前终桌后，续桌换6位桌号、原设置、新90分、第一把和新的90秒个人额度 |

## 规则说明差异

1. 最新完整规则原来写“第四碰完成后也可主动胡”，与实际操作和较早的确认说明不符。已改为：符合快照时在别人出牌的响应中直接选“胡”；先选“碰”不会再出现本次快照胡按钮，普通自摸也不能快照。本次未扩大胡牌资格。
2. 七对不加门清，也不计算普通拆解中的风对子、独占、边枝、压档；硬花和符合条件的缺一门仍算。文档现明确说明，未改既有分值。
3. 旧 `docs/RULES.md` 仍有早期V2分值和连庄说明，现标注为历史规则，并链接当前B档文档。
4. “所有分最后乘2”需要区分胡牌总分和全部账目。当前四连风/首轮跟风固定5、天胡固定400、保米目标100、外包固定50/100。非默认累计模式下胡牌与跟倍杠费可继续累乘，外包仍只按50/100；本次未改这些口径。

## 实际战绩核对

读取新服务器当前20条B档已保存记录：19次胡牌项目合计等于总分，20条内外流水与每把变化一致，相邻把余额连续，总桌内分守恒，无负桌内余额。截图牌桌153414的第8把为（成牌10＋门清10＋硬花6）×2＝52，三家各付52；第7把四连风仍各5，胡牌24×2＝48。

检查当时8份活动/归档状态，未找到花杠造成归零的历史记录；这不等于证明所有外部或更早历史均未受影响。本次不倒算或修改已保存战绩。
