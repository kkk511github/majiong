## 本地演示

- `/tests/previews/table-features.html`：显示检查入口。架牌/换听、同牌高亮、听牌、待操作框、四方位暗杠/补杠/明杠可切换；提供操作、短句、开局、扣分、结算/回放、满碰/满明杠入口。
- `/tests/previews/local-bots.html?rounds=2`：你 + 三机器人，准备 → 正式开局 → 第一把 → 单把结算 → 第二把 → 最终结算。使用原引擎，不连接服务器。
- 两把上限仅在本地辅助函数设置；正式规则支持的把数不变。提前结束条件依旧由原引擎处理，不保证随机牌局必定打满两把。
- 勾选自动演示时，本人用原托管策略（摸打/过），机器人用原 botAction；可取消托管接手。
- `testSeed`、`testSpeed` 只供本地自动化用，正式入口没有这些参数。
- iOS 独立模拟器壳：`com.jinling.mahjong.localbots`，由 `scripts/build-local-bot-simulator.mjs` 生成，仅访问 localhost，不替换正式 App。
