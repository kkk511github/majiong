## 规则和结算

- 新开桌使用南京麻将进园子 B 档，固定底分 10、门清 10、花砸 2、两家桌内归零结束；入桌 90 分，结算本金 100 分，桌费只计算一次。
- B 档牌型分值依照用户给定示例重构，全球独钓加碰碰胡合计 80 花，五花例为 100 分。天胡改为加 50，按普通自摸结算。
- 地胡以起手已听的闲家第一次出牌保持听口后自动报听为准；明杠、暗杠保留门清，碰后补杠不算门清。
- 杠分立即结算：明杠/补杠供牌者付 20，暗杠三家各付 10，花杠三家各付 20，再应用本把倍率。
- 外包只记桌外，最终战绩、导出仍统计。桌内余额 50、桌外累计 -100，最终净分为 -150，距入园仍有 50。烧庄本次不做。
- 首轮庄家出风牌，其他三家首张按座序跟同一种风牌，庄家向三家各付 5 分；某人开局前四次出牌连续打出东南西北，顺序不限，其他三家各付他 5 分。中间夹牌即失效，后续补齐不算。这两项固定每家 5 分，不乘花砸 2 或本把倍率。
- 旧规则 ID 的牌局与回放保留原算法。未新增的高阶七对档位及未修改选项沿用原有规则。
