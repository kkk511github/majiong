# 0.5.2 联机首页与对局反馈

首页的主要入口现在是「进入牌桌大厅」，旁边保留房号入桌。练习与恢复练习放在下方，不再占据主按钮。右侧通过现有 WebSocket 订阅服务器真实牌桌，优先显示有空位且人数较多的桌子，最多展示两桌；其余牌桌由「全部牌桌」进入大厅查看。

四个座位显示真实昵称、在线/准备状态；空位按钮直接提交房号与座位。开局中的房间显示局数。空大厅不伪造牌友或可用空位；断线时隐藏陈旧房间列表，连接恢复后重新显示服务器状态。服务器已有隐私和房间可见性过滤，首页只使用过滤后的摘要。

普通账号首页和大厅均不渲染开桌按钮。管理员及获得开桌授权的账号显示「开桌设置」，直接进入现有三步设置。收回权限后按钮和打开中的设置弹窗立即消失。后端仍逐次校验权限。

保留已有秦淮场景作背景，主界面改用金色主按钮、玉绿次按钮、米白房间卡。568×320、844×390、932×430（含左右安全区和 Home 指示条）验证主要入口、四个座位、状态和底部导航。首页不依靠自动轮播，也不在房间变化时播放旧对局动作。

同批包含之前已进行中的体验修正：

- 手牌稳定使用同一按钮节点，仅在确认后的摸牌/整理时移动牌面图像，触摸区域始终位于最终位置；落牌、补花、碰杠给予短反馈，尊重减少动态效果设置。
- 恢复练习、首次读取、重复/过期状态和断线重连不回放历史音效或动画。暗杠反馈不携带暗牌。
- 倒计时提示包含自己的碰杠胡响应；等待其他玩家响应时不再把上一位出牌者的托管余量显示成对方响应时间。
- 规则说明随实际海底、花砸、准备和托管配置变化；真人桌不提示添加电脑，整桌托管不提示可随时取消。
- 收回开桌授权后同步取消该账号现有桌的自动续桌标记，避免结算页面显示「0 秒后续桌」却没有后续动作。

## 验证证据

`tests/online-home.e2e.ts` 覆盖首页多尺寸、真实四客户端从首页开桌/入座/准备/开局、空大厅、断线与自动恢复。`tests/accounts.e2e.ts` 覆盖普通注册账号首页和大厅无开桌入口；`tests/permissions.e2e.ts` 覆盖授权/收回时按钮和弹窗的即时更新。原有旧式好友房仍保留兼容性测试，测试通过直接创建旧房间准备夹具进入，首页不再提供旧式建房入口。

当前测试、构建、部署和原生验证结果见本版本交付时更新的 `STATUS.md`。这次调整不宣称已完成所有体验工作或全部荔枝南京特殊规则。
