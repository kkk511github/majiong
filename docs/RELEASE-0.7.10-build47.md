# 0.7.10 / build 47

## 本次修改

- 未摸牌、其他玩家行动及等待碰杠胡响应时，也能点起、切换和放下自己的手牌。实际出牌仍由原有回合条件校验。
- 轮到自己出牌时清除提前选中的牌，防止一次点击误打；托管、断线、回放及牌局结束时保持相应操作限制。
- 点击和出牌音效与 0.7.9 / build 46 完全一致，音频源码和 9 个音频文件逐字节核对通过。新试听音效已移除。
- 本次提交同时收录此前 0.7.6–0.7.9 的规则、胡牌/点炮及回放展示、网络恢复、战绩导出等修改，以及战队日结/周结报表。报表按期末最终战队汇总，20 栏为 0，排除单人练习并包含总计行，详见 [战队定时统计](TELEGRAM-REPORTS.md)。
- 补齐独立 ExcelJS 依赖的安装说明和 Docker 构建步骤，资产检查可自动创建输出目录。
