# 0.6.4 / build 24

本次为客户端牌桌布局修复，继续使用现有服务器、账号和正式签名。

- 为选中抬起的手牌预留空间，防止遮挡自己的弃牌；弃牌尺寸不随出牌数量变化。
- 另外三家的碰杠牌放大 20%，调整牌架位置，避免碰杠牌与操作按钮重叠。
- 对家花牌采用统一边框、背景和数量标签；花牌较多时换行。
- 六种横屏尺寸检查逐张选牌、四排弃牌、多组杠牌和花牌边框；出牌箭头、碰牌来源与回放验证通过。

Android 使用原正式签名及 R8 混淆；iOS 使用 Apple Distribution Ad Hoc 签名。原生 JavaScript 混淆、不含 source map、HTTPS 和证书校验沿用 0.6.3。Ad Hoc IPA 仅适用于描述文件已登记的设备。
