# 开桌权限：固定主管理账号

只有实际登录账号 `guanli@1` 且角色为管理员、已完成初始改密，才能创建牌桌。账号以服务器数据库记录为准，不按昵称、客户端传入的role/canCreateTables或历史授权行判定。用户本次输入的`guanki@1`在服务器不存在，现有主管理账号为`guanli@1`，已在实施前说明这一拼写差异。

权限覆盖旧版普通建房、新版批量开桌、服务器机器人体验桌、自动续桌及离线机器人补桌工具。创建体验桌时，新桌归实际获权的创建者；来源正式桌的归属保持不变。

其余管理员仍保留原有会员、战队、战绩和管理收桌权限，角色不降级。普通玩家仍可按现有参赛条件进入已有牌桌。本次不创建或关闭生产桌，不重算历史记录，不改账号密码。

`/api/admin/table-permissions`保留管理员只读查询，默认显示唯一可开桌账号。POST一律拒绝，不能通过旧版授权界面授予自己或其他账号开桌。旧`table_permissions`数据保留但不再提供开桌资格，无需清空历史或修改账号行。

创建请求和重复的creationId均在读取缓存结果之前鉴权；不能用缓存请求绕过。已存在的对局不因创建权限撤回而解散，自动续桌继续检查原创建者权限。上线前当前5张正式空桌均由guanli@1创建，续桌资格保持。

## 客户端兼容

权限强制在服务器生效，不依赖先安装新版APK/IPA。旧安装包可能因为仍按admin角色显示入口而保留按钮，实际创建请求会被服务器拒绝。新版网页和后续打包客户端仅认可服务器返回的canCreateTables，权限页改为只读。其他管理员的收桌功能不跟随开桌资格一起隐藏。
