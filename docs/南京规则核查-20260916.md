## 明确保留的未定口径

1. 无三口关系的普通抢杠由谁包赔；当前分支为补杠者付桌内三份，未视为用户确认。
2. 三口责任与大杠开花同时出现时的责任优先级。
3. 暗杠是否计入口数、是否要求前三口连续来自一家，以及快照与全球独钓叠加边界。
4. 现场明杠/暗杠/花杠6/3/6花、同牌6花、四连风5花仍属当前候选基数，荔枝帮助没有给出足够细节。

这些事项属于规则口径未定，而非通过增加单元测试就能确定。已确认的“甲三口承包，丙抢丁补杠仍由甲赔”和进园子桌外50/100继续保留。

测试实跑数量与构建证据统一记入 `RELEASE-0.7.1.md`。测试通过证明当前实现满足这些用例，不代表穷举全部牌型或解决以上地方差异。
