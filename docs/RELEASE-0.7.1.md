# 0.7.1 / build 37

## 本地改动

- 工作目录此前没有 `.git`；已初始化本地仓库并将现有源码提交为 `305b304`。之后本轮修改全部保持未提交；未推送。
- 42种麻将牌共用更鲜艳的彩色刻纹、白色树脂牌身、清晰倒角和绿色侧边。imagegen 生成牌背树脂材质，20组生产方向贴图覆盖手牌、弃牌、花牌、碰杠与隐藏牌背；React 听牌/帮助/结算小牌也同步使用同一套牌图。[素材与最终提示词](./IMAGEGEN-0.7.1.md)。
- 战绩已读仅管理员可见，按管理员账号分别记录。打开整桌详情且内容成功加载后才向服务端写入；刷新列表本身不标记。成功后绿色“✅ 已读”，失败显示重试保存；不同管理员互不影响。状态保存在独立 SQLite 表，重启、再次存档和换设备不清除。会员不能写入也收不到状态字段。
- 登录、注册和首次改密的输入区域根据可见视口调整，焦点输入框自动滚入表单可见区；提交按钮与表单关联。Android 明确使用 adjustResize；密码显示按钮保留焦点。真实 iOS 键盘上方显示登录/注册控件。
- [南京规则核查](./南京规则核查-20260916.md)：主要玩法已实现并测试；无三口抢杠、三口与杠开责任、暗杠/快照边界和现场汇数值仍有未定口径，不能宣称规则全部完整。本轮保留既有用户确认案例和历史规则版本。
