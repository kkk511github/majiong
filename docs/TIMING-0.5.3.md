# 0.5.3 联机倒计时

## 修正

旧版用手机的 `Date.now()` 减服务器截止时间。设备日期快慢数小时，准备、出牌、累计超时及结算等待就会显示错误。本版通过服务器消息时间戳建立单调时钟，连接建立、每 30 秒及返回前台时用 ping/pong 校准往返延迟。时间戳只用于显示；真正开局、踢人和托管仍由服务器执行。

校时消息独立于准备、碰杠胡等命令确认，不会解锁尚未确认的操作，也不会改变牌局、恢复累计额度或重放上一条动作。兼容不支持校时的旧服务和本机练习。网络延迟不对称仍会产生少量显示误差，不能视作网络完全无延迟。

未准备玩家的座位直接显示剩余准备秒数。正常出牌时间用完后，当前玩家显示“累计余时”和对应托管结果。断线期间中央盘显示“重连中”，个人计时环暂时隐藏，恢复后继续显示真实剩余时间。

## 验证

- 时钟测试覆盖设备快慢 6 小时、游戏中修改日期、迟到样本、前台重新校时与连接更换。
- 客户端验证 pong 不会确认准备动作，旧连接不能污染新牌局，退出后停止定期校时。
- 真实服务验证回传客户端计时标识，但服务端状态不受客户端传入时间影响。
- 四独立浏览器分别偏移 −6 / +6 / −12 / +12 小时，真实完成开桌、入座、手动准备和四人开局，仍显示 10 秒内的正常倒计时。
- 568×320、932×430 的状态夹具验证准备倒计时、正常时间切换为累计余时、断线隐藏与重连后额度不重置。该组使用真实身份认证与校时服务，对局快照是测试夹具。
- 完整回归及发布结果记录在 `experience-0.5.3-check.json` 和 `STATUS.md`。

本版继续保留普通账号无开桌入口、授权即时生效、联机首页与真实座位订阅。没有改变胡牌分值或启用尚未核准的风罚分、比下胡。
