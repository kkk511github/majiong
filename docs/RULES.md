# 南京麻将：本版可执行规则

**本版执行 `nj-casual-v1` 休闲规则，尚未完成与微乐/荔枝南京麻将的全部计分核对。** 已读用户提供的荔枝安装包内南京玩法说明和设置截图；花砸2、海底捞月及用户明确的保米、入桌分和计时设置已接入，风罚分和比下胡仍未启用。以下记录当前程序行为。

本版规则标识 `nj-casual-v1`。南京麻将存在不同地方和平台口径。以下规则与程序对应，试打时以此核对，后续规则变更需使用新版本标识，不能悄悄修改进行中牌局。

参考资料：[唐人游南京麻将规则](https://nanjingmj.uc55.com/Rule/Detail/201802_000241.html)、[来游戏南京麻将规则](https://static.laiyouxi.com/games/44.html)。资料中的计分和流局口径不同，本版是下述明确选择的休闲玩法，并未声称完全复制其中任何一个产品。

## 牌组与行牌

- 144 张：万、筒、条、东南西北各四张，共 124 张行牌；中发白各四张加四季四君子八张，共 20 张硬花。
- 四位玩家。每位起手 13 张行牌，庄家再摸一张。花自动亮出并从牌尾补牌。
- 可碰、直杠、补杠、暗杠，不可吃。进行中自己的暗杠可见，其他玩家只看到牌背；本把结束后亮牌。推送消息也不包含他人暗杠牌型。
- 一次打牌同时产生胡、碰、杠时，先等所有可响应玩家表态；胡牌优先，支持一炮多响。无人胡时执行有效碰杠。
- 弃胡后，自己下次出牌前不能再胡；弃碰后，自己下次出牌前不能再碰同种牌。
- 未开启海底捞月时，牌墙剩余 16 张流局；开启时摸完牌墙才流局，最后四张内自摸加 20 分。庄家胡或流局继续坐庄，否则下家坐庄；局数按开桌选择，连庄也计一局。开启两家归零时可提前结束本桌。

## 胡牌分值

普通成牌为四组顺子或刻子加一对将，也支持七对；不同牌型可按下表叠加。开门普通小胡至少四张硬花；门清或大胡不受此限制。

| 项目               | 分值与条件                                                         |
| ------------------ | ------------------------------------------------------------------ |
| 成牌               | 20                                                                 |
| 硬花               | 每张 2                                                             |
| 门清               | 20；暗杠仍视为门清，其他副露破门清                                 |
| 混一色             | 40；一种数牌花色加风牌                                             |
| 清一色             | 60；仅一种数牌花色；不叠加混一色                                   |
| 字一色             | 本版按清一色 60 计算                                               |
| 对对胡             | 40                                                                 |
| 全球独钓           | 60；四组副露后的成牌，另计对对胡                                   |
| 七对               | 80；不另计门清                                                     |
| 豪华七对           | 160 / 240 / 320，分别含一 / 二 / 三组四张相同牌                    |
| 无花果             | 门清且没有硬花，加 40                                              |
| 风刻、风对、缺一门 | 各 1 个软花，每个 2；纯色不另计缺一门                              |
| 独占、边枝、压档   | 成牌前只有一种结构上的听牌，满足对应形状时加 2，同一听口不重复叠加 |
| 压绝               | 边枝或压档胡到已被碰出的同种牌，加 40，取消该听口的 2 分软花       |
| 补花胡             | 20                                                                 |
| 暗杠开花           | 20                                                                 |
| 明杠或补杠开花     | 40                                                                 |

上表花分按“花砸2”开启计算；关闭时硬花和软花每个计 1，基础胡牌分不随该开关翻倍。

当同一手牌有多种拆解方式时，取合法的最高分拆解。单一听口由牌型结构和自己已持有牌的数量计算，不因对手暗牌推断。

## 收支

- 点炮由放炮者支付一份胡牌分数；自摸由其他三家各支付一份。
- 抢补杠胡视为补杠者承担三份，本次补杠不收杠分。
- 明杠或补杠开花由原供牌者承担三份。
- 四组副露中至少三组由同一家供牌时，本版由该家承担三份。
- 直杠、补杠：原供牌者付 12。暗杠：其他每家付 6。花杠：其他每家付 12。
- 四张中、四张发、四张白、四季或四君子分别构成花杠；起手补花集齐也即时结算。
- 杠分即时入账，流局不退杠；一炮多响分别结算，每笔牌局收支相抵。开启两家归零时，每次支出最多扣到零；余额不足支付多位胡牌者时按应收比例分配，不按先后顺序独占余额。
- 积分无充值、提现、兑换、转让功能。

## 入桌与整桌战绩

- 正式牌桌每人本金 100 分，扣桌费 10 分后入桌余额为 90。桌费不进入其他玩家余额。
- 最终记分＝（桌上余额−100）×开桌所选倍率 0.2 / 0.5 / 1；可为负值。四人最终记分合计为 −40×倍率，对应四份桌费。练习及旧牌局使用各自保存的结算本金，不能套改历史记录。
- 开启保米后，胡牌结算触发两家归零时，该次胡牌者不足 100 分的部分由其他玩家中余额最高者补足，受实际可付余额限制。用户例中 24 分补 76 到 100，倍率 0.5 时该玩家最终记分为 0。
- 管理员只查看每桌最终汇总，包括房号、结束时间、实际局数、四家输赢及倍率后的记分；不会把一桌八把拆成八条管理战绩。

## 开局与计时

- 普通账号没有开桌入口；管理员和单独获开桌授权的账号可开桌。正式牌桌为四位真人，默认全员在线、手动准备后自动发牌。
- 四座坐满才开始默认 10 秒准备倒计时，到期未准备者自动离座。
- 每次出牌或碰杠胡响应先有 10 秒，超出的部分消耗个人整桌累计 90 秒余时；下一把、重连均不补回。默认用完后整局托管。其他托管选项按桌设置执行。
- 默认联机托管遇到合法自摸或点炮会自动胡牌，其他碰杠响应自动过牌；无胡牌时打出刚摸到的牌。练习陪练使用基础理牌策略。
- 结算默认展示 10 秒；自动续桌以配置和当前开桌权限为准。
- 客户端从服务器时间戳和校时往返建立单调时钟，手机修改日期不改变正常显示。真正的准备、托管和结算截止时间始终由服务器执行。断线时隐藏失去同步的数字，恢复后重新同步。

## 尚未启用、需要进一步定稿的地方规则

比下胡和连续翻倍；快照（第四碰后直接成牌）；天胡地胡与其他牌型的叠加；四张相同弃牌罚分；暗杠是否破门清；留牌数量和庄家轮换的其他口径。

这些条件当前不启用，不应在试打时将它们作为已经实现的规则。计分函数预留了天胡地胡、翻倍上下文，但对局引擎尚未触发，因此不能据此声称功能已完成。
