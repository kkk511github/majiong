# 0.7.0（构建 33）

- Cocos Creator 牌桌和回放共用 2.5D 预渲染牌图与统一布局。
- 上下家弃牌保持笔直，花牌贴合卡槽并保留可见厚边；多花牌和四组碰杠分别保留空间，第四张杠叠在中间。
- 过、碰、杠、胡固定在自己手牌右上方的一行；托管单击取消，人类托管摸什么打什么并自动过碰杠胡。
- 战绩按日期查看整桌总分，详情查看每把及回放 ID；战队名称仅管理员可见。
- 延续正式签名、原生 JavaScript 混淆、Android R8、HTTPS/WSS 与证书固定。

验证：218 项单元及服务端测试；22 项 Cocos、回放、语音、音乐、后台恢复 Chromium/WebKit 检查；12 项战绩及回放 Chromium/WebKit 检查。原生 Release、Ad Hoc 导出和 iOS 模拟器构建通过。完整旧版 DOM 牌桌用例不适用于 Cocos，未作为本版本验收结果。

IPA 使用 Ad Hoc 描述文件，仅适用于已登记的设备。签名私钥、配置、数据库及安装包不提交到源码仓库。
