# 无花果资格修正（359401 第7把）

2026-09-28用户确认：零硬花、门清可以正常胡；碰过牌且仍有碰牌副露时，必须另有清一色、混一色、对对胡、全球独钓等独立免花资格。无花果本身不是独立胡牌资格。

## 原因与修正

原B档在硬花门槛检查前执行 `big("无花果", values.noFlower)`，其默认参数把 `flowerExempt` 设为真。因此0硬花普通开门牌被错误放行，反而1～3花会被拦截。原测试和部分规则文案也保留了该错误例外。

现在先根据门清和其他独立免花牌型检查硬花门槛，再给符合资格的零硬花胡牌加30分无花果；无花果仍属于可触发比下胡的计分项目，但不修改花数豁免。压绝、大小杠开花、海底捞月、抢杠赔付和倍率不能单独放行0～3硬花普通开门牌。压绝或海底配清一色等免花牌型仍合法。

当前全部已成立副露为杠（包括暗杠、直杠、补杠）仍算门清；有剩余碰牌则不算门清。本次不改变杠费、外包、抢杠方向、其他胡牌加分或旧v1/v2规则。历史保存的账单与回放不重算。
