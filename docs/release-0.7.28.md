# 金陵麻将 0.7.28 / build 65

本版统一快照成胡的显示，避免计分副本中的第四组被展示成普通全球独钓。

- 带snapshot标记的结果，在胡牌特效、结算标题、战绩与回放中统一显示“胡”，语音短语统一为“胡了”。普通实际四组落地的全球独钓保持真实牌型提示。
- 快照明细将原全球档项目标为“快照加分”；摘要优先显示该胡者实际外包收款，表内另列“快照参考牌分”。例如498046第3局参考204，钟山向秦淮实际外包100，存档金额不变。
- 用户最终确认：必须头三嘴同一供牌人；成立后第四嘴来自任何人均可。甲甲乙甲不能用累计口数补成三嘴。临时累计提议已全部撤回，计分引擎与此前版本相同，未部署累计逻辑。
- 更新当前规则说明中已经过时的压绝门槛与抢杠三方收款文字，三清明确包含同花色公开碰杠；保留用户自定分值。
- 延续build64的仅短句、无录音发送及麦克风权限、账号键盘修复。

核验：910项单元/集成测试、4项Chrome/WebKit完整显示回归通过；基础牌型37项独立正反例通过，533条既有实体牌例重新计分一致。核查的范围与仍需定口径的地胡缩听、海底计数时点，见[完整核查与案例](规则核查与外包案例-20260920.md)。没有因其他平台的地方分值不同而擅改本软件算法。
