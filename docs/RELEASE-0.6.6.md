# 0.6.6 / Android build 26

安卓牌桌单独采用较大的麻将尺寸：手牌、上家下家牌背、对家牌背、碰杠牌和花牌以 0.6.5 为基准放大 30%。手牌使用底部完整宽度，仅新摸的牌保留间隔；小屏幕边距随安全区域适配。

花牌移到手牌上方的独立区域，较多花牌使用更宽的多行框。侧面的手牌与碰杠牌分道；公开组合较多时按组排列，全部牌面保留可见。右下操作按钮给抬起的手牌预留空间。头部文字保持在对家手牌上方。

弃牌优先采用更大的尺寸，同时受屏幕可用空间约束，因此不保证每种手机的弃牌都线性增加 30%。尺寸只依赖视口和预留区域，追加弃牌、换行不缩放。横排每排八张，侧排根据屏幕高度每列六或七张，箭头随对应行列定位。

验证：640×360、800×360、915×412、960×432 四种 Android 视口；自动核对手牌、花牌、碰杠牌和牌背的 1.3 倍尺寸，满牌池换行、抬起全部手牌、四组杠、三组碰及五张余牌、10/15/20 张花牌、操作按钮点击区域与无遮挡。另六种既有视口、两项出牌箭头检查通过。测试使用浏览器模拟 Android 视口，并非安卓真机实测。

本次为安卓客户端更新，iOS 安装包和服务器保持 0.6.5。沿用正式签名、R8、JavaScript 混淆、HTTPS 和证书校验，账号及联机协议保持兼容。
