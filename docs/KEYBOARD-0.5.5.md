# 0.5.5 横屏输入与开桌入口

普通注册账号的首页和牌桌大厅均不渲染开桌按钮；管理员及具有独立开桌授权的账号才显示。撤权后立即隐藏入口、关闭已打开的设置。后端仍逐次核验权限，授权开桌不会授予管理员战绩权限。

iOS WKWebView 弹出键盘时，布局视口不会总是随之缩小。原先加入房间的确认按钮可能被数字键盘及输入工具栏遮住。现按 VisualViewport 的实际高度和偏移安排输入区域：房号弹窗采用并排输入与确认；登录、注册将输入区设为可滚动区域，提交按钮固定在键盘上方。控件保留 44 像素高度；键盘收起后恢复完整界面，双指缩放不会误触发此布局。表单与提交按钮通过原生 form 属性关联，仍执行必填、长度和密码确认验证。

## 实际原生检查

Mac 解锁期间，在 iPhone 17 Pro / iOS 26.5 模拟器实际点击验证了房号数字键盘、输入 12、六位校验错误和关闭恢复；输入与加入按钮保持可见。个人页昵称输入及保存按钮在键盘上方可用，测试字符删除后保留原昵称，没有提交修改。

随后在独立 QA bundle 中复现登录键盘遮挡，增加了上述登录/注册布局。最后的 44 像素输入高度修正已通过浏览器几何检查，但 Mac 再次锁屏，最终原生登录/注册键盘尚未完成触摸复核。QA bundle 已移除；正式资源没有 QA 音频探针或标记。

音乐和音效未在本版改变。仍需实际原生音频、中断及后台恢复检查；不能以 Web Audio 浏览器结果代替听感或电话中断验证。
