# 0.7.0 源码更新（2026-09-15）

原生工程版本为 0.7.0 / build 34。本次提交更新源码和可复现的 Cocos Web 运行包，不代表 IPA、APK 或服务端已发布。用户要求等待规则修改确认后再打包。

- “我的”采用个人资料卡与设置列表，照片、昵称、声音和密码通过独立弹窗编辑。普通成员不显示管理及开桌授权入口，服务端继续校验权限。
- 注册、登录、修改密码最低 4 位；支持选择照片、预览保存及恢复默认头像。服务端重新编码头像并去除元数据，牌桌同步照片，隐私桌仍隐藏其他玩家头像。
- 碰牌来源改为金色内凹箭头，固定在中间牌面并指向供牌者。明杠第四张叠在中间并承载来源标记，暗杠不展示牌面或来源。
- 自己的碰杠使用带厚度的平放贴图，两侧花牌紧贴成列；iOS、Android、Web 和回放共用 Cocos 场景与预渲染资源。
- 同步当前南京进园子、敞开头、比下胡、外包责任及桌内/桌外独立记分开发代码，战绩和回放显示对应明细。旧牌局按既有规则版本回放。测试通过不等于所有地方规则口径已最终确认。
- 服务端健康检查返回实际软件版本。头像上传入口补充请求大小限制，sharp 为生产依赖。

当前源码的 28 个单元及服务端测试文件、280 项测试通过。推送前 Cocos、TypeScript、Vite 完整 Web 构建通过，8 项 Chromium/WebKit 检查通过，覆盖两种横屏尺寸的规则选择、实际开桌、桌外记分明细和回放。此前“我的”页面 12 项 Chromium/WebKit 场景及最终箭头 2 项 Chromium/WebKit 场景通过。此前生成的原生包不包含本次所有修改，不能作为本次更新交付。

签名私钥、本机环境配置、数据库、会话、安装包和本地测试输出不提交到仓库。
