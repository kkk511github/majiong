# 牌桌动作与碰杠操作

碰、杠、过使用手牌上方靠右的玉绿矩形按钮，依服务器实际可用动作显示。胡牌、抢杠及多张可杠选择保留；左下小提示显示供牌者和真实牌面。中央余牌、余花、风位和把数保持可见。

碰、明杠、暗杠、补杠确认后，本人的动作提示短暂出现在自己手牌中央，其他玩家在各自门前显示。扣分提示仍只出现在实际付款玩家处，补花和碰牌本身不增加收费。

牌张沿连续轨迹移动并同步缩放、阴影；动作期间收到新位置时从当前画面续接。暗杠三张背牌和一张明牌分别跟踪，归位后刷新不再重播。拖牌释放点保留到出牌结果返回，断线、拒绝或超时可以恢复。首帧、换桌、换把、恢复连接与回放跳转以当前盘面恢复，避免飞牌补播。

上家新摸牌跟随剩余手牌，下家新摸牌仍在最上方，对家新摸牌仍在最左边。侧边摸牌与相邻牌保留固定小间隔，碰杠缩短手牌后不保留原来的大空隙。

本地设计页位于 tests/previews/table-motion-v2.html。正式牌桌与该页面共用布局、动作实现及控件。设计参考和完整生成提示词保存在 docs/design/。
