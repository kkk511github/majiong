# 金陵麻将 0.7.22 / build 59

本次完成八项牌桌体验修改：

1. 进行中的牌桌只能由管理员解散。普通成员保留托管；管理员在桌内或大厅均可收桌，收桌后所有人返回大厅且不自动续桌。
2. 无需先选牌即可直接向桌面拖出，保留点选、再点出牌及快速双击。切换回合、断线、托管、取消手势及等待服务器确认时防止误出和重复出牌。
3. 下家摸到的牌置于最上，对家置于最左；对家原有手牌和碰杠牌保持位置。
4. iOS 原生头像选择菜单使用中文，并在模拟器复现旧英文配置与新中文配置对比。
5. 移除单人练习入口和旧客户端的练习启动能力。新增管理员专用的服务器体验桌创建消息，复制现有正式桌设置，保留三名已准备机器人，正常进入服务器开局、结算和续桌流程。体验桌战绩可查看，不进入积分流水、日结和周结。
6. 托管采用机器人同一套合法决策，自动胡、碰、杠及选择弃牌。
7. 自家和对家碰杠牌与手牌之间留出间隔。
8. 碰杠胡响应提示移至左下方；东南西北、剩余牌、剩余花及把数始终可见。
