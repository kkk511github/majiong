# 金陵麻将 0.5.1 · build 11

## 开桌授权

管理员登录后进入“我的 → 开桌授权”，填写对方完整账号，核对昵称后授予权限。对方需先注册。可在“已授权”列表收回权限；立即生效，无需重新登录。

获得授权的牌友可以建桌并收起自己的空桌/已结束牌桌。全部牌桌最终战绩和授权管理仍只归管理员。撤权不打断当前牌局，但会阻止新开或自动续桌。权限跨重启保存，管理员原密码保持不变。

## 安卓图标

重做自适应图标、安全留白和安卓 13 主题单色图标。新 APK 包名与签名延续原版，可覆盖升级。

## 公平性与胡牌

安全随机整数洗牌；修复其他客户端能收到暗杠具体牌型的问题。1000 局固定种子模拟 925 胡、75 流、0 卡住；三种横屏下自摸/点炮按钮可操作并进入结算。完整说明与边界见 FAIRNESS-0.5.1.md。

风罚分、接庄比下胡尚未核准实现；不能承诺绝对公平或每局一定有人胡。

## 验证与安装

108 项逻辑测试、88 项界面测试通过；线上鉴权、WebSocket 和原生跨域验证通过。Android 11 模拟器覆盖安装 0.5.1 成功；5 档密度的图标主体均在安全圆内，APK 编译资源含 Android 13 单色层。iOS 模拟器已打开，Ad Hoc 包包含当前 iPhone 的注册设备 ID；本次手机未连接，未安装 0.5.1。
