# 全面体验优化验收清单

目标：综合优化南京麻将 App 的 UI 细节、动画、交互逻辑和用户体验，参考用户提供的荔枝竞技截图与安装包。全程横屏，保留已经选定的雕刻牌面、秦淮河大厅和绿绒牌桌。以前的版本说明仅作历史证据，不能代替当前验收。

当前目标回合分类：有进展。0.5.9 已完成两端安装包、正式签名与资源验证，新增每把亮牌/分数、10 秒续局、私有听牌、10+90 秒可取消托管、两行三列六条、台面/风位与二次点击出牌调整；补花改为仅语音。随后按反馈统一四家弃牌每排 8 张，固定尺寸，全部留在桌面；头像和花牌分开摆放，手牌立起与新摸牌不覆盖弃牌，操作提示移到底栏。最终 162 项逻辑/服务、141 项完整界面检查通过；两端包已重编译，源码清洁构建的网页资源与安装包一致。原生 iOS 音频修正证据与本轮 UI 操作边界详见 IOS-VOICE-0.5.9.md、TABLE-FLOW-0.5.9.md。综合目标仍未完成。

## 当前检查发现

1. 0.5.1 的行牌基本是瞬间变更，缺少确认后的摸牌整理、落牌、补花和碰杠反馈。
2. 真人建桌等待页仍提示“添加电脑”；通用规则页的“剩16张流局”“托管可随时取消”与海底捞月、整局托管等设置冲突。
3. 音效在重新进入进行中的牌局时可能把恢复状态当作发牌，断线后也可能播放错过的历史事件。
4. 撤回开桌权限已阻止自动续桌，但旧牌桌设置仍标记自动续桌，结算界面可能停留在“0秒后续开空桌”。

本清单保留完整范围。已勾选项目表示下表所列实现、浏览器实际渲染和交互证据闭环；原生键盘、真实音频中断等跨流程项目单独保留，不能由浏览器结果代替。

## 0.5.3 本轮交付（有进展）

手机日期和服务器截止时间直接相减的问题已修正。校时不占用游戏命令确认，断线/睡眠前的回复不会修改新的时间基准；个人累计超时不因重连或下一把恢复。准备秒数显示在对应座位，累计余时提示说明当前托管结果，断线不展示失去同步的计时环。

当前证据：122 项逻辑/服务测试；99 项完整界面回归；最后前台边界修改后 10 项相关界面复测通过，期间一次无堆栈 JSON 异常及重跑结果如实保留。四真实客户端带不同手机日期偏差，仍完成满四手动准备开局。iOS 原生成功点击个人页、大厅和首页，普通账号两个开桌入口均不存在；最终包已重新安装启动。详见 TIMING-0.5.3.md 和 experience-0.5.3-check.json。

下一步优先补尚未闭环的原生键盘/前后台长时实战、异常网络下结算续桌、性能与音频中断证据；避免重复改动已经通过的首页结构和手牌间距。地方规则差异需基于安装包说明和可靠证据核对，不能把本版计分直接称为完整荔枝规则。
