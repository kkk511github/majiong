# 0.6.7 / Android build 27

修复安卓两侧手牌与 iOS 排列不同，以及暗杠、碰牌挤入弃牌区的问题。上家、下家的牌面分别朝向对应玩家；未公开手牌保持连续一列，每组三张碰牌或四张杠牌完整排列。较多组合按整组使用不同列，不再把一组拆成 L 形或 2×2 方块。保留 0.6.6 的牌面放大比例。

为侧面手牌、公开组合、花牌、弃牌和操作按钮划定独立位置。修正牌背图片的定位，避免元素占位正常但实际图片叠在一起。玩家姓名、方位和积分使用明确行高，花牌框避开身份信息；对家花牌仍随对家手牌显示。中央倒计时保留独立数字区域，与四个方位字分开。

本局结束后服务器提供的公开手牌也保持相同朝向；较长手牌使用第二列，避免盖住自己的手牌。本次不改变服务端可见性规则：对局中的其他玩家暗杠仍使用无牌面信息的四张牌背。

验证覆盖：640×360、800×360、853×384、915×412、960×432（左右安全区域 24px）、1280×576 六种 Android 视口，包含用户截图相同比例；连续牌背及实际图片边界、1.3 倍牌面、满牌池追加与换行、抬起手牌、四组杠、三组碰、暗杠与碰牌混排、10/15/20 张花牌、操作点击区域、积分标签与结束后亮牌。另六种既有通用视口和两项弃牌箭头检查通过，TypeScript 类型检查通过。

上述为浏览器模拟 Android 视口验证，未连接安卓真机进行安装实测。iOS 布局与安装包、服务器版本保持不变。安卓继续沿用既有正式签名、R8 和 JavaScript 混淆；与前一正式版兼容覆盖安装。
