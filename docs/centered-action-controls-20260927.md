# 操作区缩小、移中及满牌预览

用户反馈单胡在最右边容易被手挡、四按钮过大、胡牌提示遮挡弃牌。

- 操作组以设计坐标x=800为固定中心，位于本家手牌上方；单按钮不再贴右边。按住期间沿用已有位置/动作集合锁定和防穿透。
- 按钮视觉上限70→56px，字形占比65%→57%；触控热区仍至少44px。过和胡保留额外间隔。火焰/蓝色外圈保留。
- 胡牌/自摸提示并入左侧原来牌提示保留区，不再悬在弃牌上方；同时消除重复来牌卡。显示牌面、来源及可胡/自摸。来牌保留区右边界收至136，避免满碰时左侧手牌下端。
- 实际动作合法性完全由现有引擎决定：单胡自摸、单碰+过、单杠暗杠、胡杠碰过四项组合。未添加虚假按钮，不改变玩法。
- DEV现有主入口增加满牌选择和整桌预览模式，不加入生产构建：`/?actionStudio=1&crowded=1&tableOnly=1&choice=all`。choice支持hu/pung/kong/all。

满牌场景使用唯一的144张物理牌：本家13或14张、桌上64或65张弃牌、20张花牌、另三家六组碰牌，剩余牌墙保留。不是四家各27张弃牌的非真实超载场景，不对未测牌型宣称零遮挡。
