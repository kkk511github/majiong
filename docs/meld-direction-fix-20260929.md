# 对家副露来源方向修复

2026-09-29。本次仅修复表现层，未变更供牌记录、规则、计分或网络消息。

## 原因与范围

3D 布局把对家副露区域从左向右填充，同时按逻辑索引递增排列每组牌；但对家自己的左右顺序与屏幕相反。因此对家碰、明杠、补杠在来自两侧玩家时，横牌落在相反一端。回放切换视角也受影响。旧测试主要验证逻辑横牌索引、旧布局或箭头，未验证新 3D 模型的实际位置。

在每组对家牌摆放时反向遍历，不改变逻辑索引、供牌人、各组顺序或整排预留边界。补杠上层仍对齐逻辑中间牌。
