# 真实 Cocos 3D 牌面本地试验

这是可运行的 Creator 3.8.8 试验，不是生成效果图。只在本地预览中使用；没有连接线上账号、替换正式牌桌或改变玩法/计分。

## 运行

1. `node scripts/build-cocos-3d-preview.mjs`：将现有 Creator 项目复制到被忽略的 `output/cocos-table-3d-preview`，仅在副本启用 3D 并加入标准材质。正式项目设置和已提交的运行时包不变。
2. `npx vite --host 127.0.0.1 --port 5199 --strictPort`。
3. 打开 `http://127.0.0.1:5199/tests/previews/table-3d.html`。

需要本机 Creator，可通过 `COCOS_CREATOR` 指定安装路径。页面有四个玩家视角，以及正常、统一花牌尺寸、满碰、满明杠、暗杠/补杠、27 张弃牌压力场景；也可切回原版比较。

## 本版范围

- 底图、HUD、头像和牌值墨迹来自现有项目。手牌暂时保留生产 sprite；弃牌、副露、花牌采用真实 MeshRenderer 几何牌体和材质，接触阴影为简化的透明平面，不是完整阴影贴图方案。
- 3D 牌体按所属座位整体旋转，字顶朝向玩家前方。侧家不再共用面向观察者的字面方向。旋转改变牌面朝向，不把厚度和灯光作为图片一起旋转。
- 试验桌面改为 1280×680；独立分配手牌/副露、花牌、弃牌区域，保留中心风位和余牌/把数的净空。
- 本家副露宽50，相对65宽手牌缩小约23%，平放投影明显矮于竖立手牌。上家副露起点有顶边安全距离；组内相接，组间留白。
- 所有座位的花牌统一物理尺寸0.30×0.42、厚0.054；屏幕宽高会随座位旋转互换，但模型尺寸不改变。
- 暗杠/补杠第四张使用中间目标牌的模型位置和朝向，仅增加层高。

测试：`npx vitest run tests/table-3d-layout.test.ts`、`npx playwright test -c tests/table-3d-browser.config.ts`（先运行上述预览服务）。

这不是正式3D完整游戏：尚未转换竖立手牌、接入真实操作或做移动端性能验收。压力场景是视觉测试数据，不应当作合法144张实战牌局。后续正式接入仍需用户确认及单独测试、打包。
