# 0.7.5 / build 41

## 变更

- 对家弃牌满九张后，新一排向屏幕上方、靠近对家手牌延伸。三排占用的整体范围保持不变，已出的牌不重新移动。
- 上家继续从上往下，下家从下往上；四种座位视角使用同一套布局。
- 原生包的应用 JavaScript 使用 RC4 字符串混淆，并覆盖 Vite 直接复制的 Cocos 应用代码。不开启影响渲染性能的控制流扁平化或反调试循环。
- 原生构建自动检查所有网页资源：发现源码映射、开发源码、私钥、数据库、环境配置或明文服务地址时停止构建。
- 纳入本地已完成的音频前后台恢复修复：有限重试、音频时钟卡死检测、牌桌手势解锁，保留静音设置。

## 安全边界

本版是代码混淆加固，不是不可逆的安装包加密。运行时所需的解码器也在客户端内，不能作为秘密存储。

HTTPS/WSS、Android R8、禁止明文流量、关闭 WebView 调试、禁止 Android 备份、发行签名、系统证书校验和双公钥绑定继续保留。Android 的证书绑定域名配置和 iOS 的证书校验目标仍能暴露连接地址，网络连接的目的地址也能被观察到。

用户当前没有代理/CDN 入口，继续使用现有服务器。服务器真实地址尚未隔离，不能宣称隐藏 IP、域名或阻止所有逆向；要隐藏源站，后续需要代理入口与源站访问限制。密钥、数据库和权限判断不下发到客户端。
