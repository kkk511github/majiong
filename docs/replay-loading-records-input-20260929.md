# 回放首帧等待与战绩输入缩放修复

2026-09-29。本地源码及共享 Cocos 运行包更新；未部署网页、未同步原生工程、未打包或发布 APK/IPA，未修改版本策略、玩法、计分和历史数据。

## 回放

- 原回放时钟只依赖播放状态和回放数据，不等待牌桌画面。Cocos 原 `ready` 消息表示资源完成，早于收到并绘制回放快照；提前撤掉遮罩还会暴露初始桌布。回放弹窗本身也保留了绿色背景。
- Cocos 在回放快照完成场景绘制后的 `Director.EVENT_AFTER_DRAW` 回传 `frame-presented`。父页面核对 iframe 来源、channel、回放标识、局数、进度及视角，才解除加载遮罩。
- 播放、进度操作、声音和自动隐藏控制条受画面就绪状态约束。加载失败/图形恢复期间冻结进度；重试画面成功后继续原位置。切换回放或重新查询重新等待，不复用上一局的就绪状态。
- 统一回放弹窗及内容区的蓝色底色。保留手动播放，不新增自动播放。

## 战绩输入

- 战绩房间号输入在窄屏样式中被设为 12–13px，改为更高优先级的 16px，避免触发 iOS 小字号输入聚焦放大；回放 ID 输入同步保护。
- 查询提交后释放输入焦点，并声明搜索键；不禁用用户手势缩放，不通过强制修改 viewport 比例复位页面。
