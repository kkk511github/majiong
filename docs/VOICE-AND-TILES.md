# 报牌、同桌语音和牌桌反馈（0.6.11）

## 南京话报牌

使用用户提供《南京话语音包.zip》中的“南京麻将_njyz”一套，男女录音均随包安装；默认男声，已主动选择女声的设置仍保留，在声音设置中切换、调节音量和试听。该资源不是本项目原创录音。来源文件及 SHA-256 见 `nanjing-voice-import.json`；旧合成音库已移除，旧来源清单仅作为历史记录保留。

音库包含 31 种可打出的牌名，以及碰、杠、听、胡了、自摸、补花。原 ZIP 的筒、条文件名和部分动作文件名与录音内容不一致：实际 33–41 是一至九筒，17–25 是一至九条，两种声音按实际内容导入。原二万说“双眼皮”，现由同一说话人的“二”“万”原录音音节剪辑为直接牌名，原文件、时间范围、淡入淡出和 PCM 指纹均记录在导入清单中。暗杠、补杠共用“杠”，不播暗牌牌名；特殊胡牌保留文字和效果，使用通用胡牌录音。语速为原录音的 90%，保持音高，统一响度、去除首尾静音。听感仍需用户在实际手机扬声器上确认。

安装 Python `av`、`numpy` 后运行 `python scripts/audio/import-nanjing.py /路径/南京话语音包.zip`，生成 `public/audio/nanjing-{female,male}.wav` 和 `src/nanjing-{female,male}.json`。原 ZIP 不随源码上传。

## 同桌语音

仅在用户按住麦克风按钮后录音，松开发送、上滑取消，最长 15 秒。权限拒绝不影响打牌；离桌、断线、进入后台或松开时仍在等待授权，均取消录音并释放麦克风。WebKit 必须在申请麦克风前切换到 `play-and-record`，失败、取消、结束后恢复原音频模式。录音期间游戏声音静音；收听牌友语音时背景音乐降低。

16 kHz 单声道 PCM 通过带登录令牌的独立 HTTPS 路由上传。服务端验证登录、参与资格、当前同桌连接、时长、格式、大小和频率，上传完成再次确认资格，仅经 WebSocket 转发给当前同桌玩家。音频不写磁盘、数据库、战绩或回放；客户端仅在内存中保留最近 8 条、60 秒有效，可重听或在设置关闭播放。接收者仍可能另行录制。

Nginx 使用 `deploy/nginx-mahjong.locations` 中的语音专用限额；游戏 JSON 命令保持原有 8k 上限。iOS 与 Android 的麦克风权限用途已写入原生权限声明和隐私说明。自动化录音检查使用合成音频，不访问真实麦克风。

## 牌桌

两端共享同一套几何布局。对家花牌位于对面上方独立区域，侧面花牌按列数为相邻手牌留位。上、下家暗手各是一条连续牌列，碰杠牌按座位旋转，三家使用相同尺寸。

弃牌尺寸在 0.6.10 视口上限计算后再放大 20%，不随弃牌数量变化，四家保持同样大小；自身、对家每行 8 张，两侧每列 6 张。过、碰、杠、胡、自摸保持一行，按钮从 40/34px 放大到 48/44px，在自己手牌上方寻找空位，避开牌面。听牌提示自动显示在自己的手牌旁，展示选中牌打出后可胡的实际牌面；等待碰杠胡选择时不显示弃牌预览。选中手牌即高亮牌河中的同种牌，第二次点击才打出。

自己的头像与分数位于右下角。数字倒计时和四个方位使用独立网格，数字居中，不随位数改变位置。碰牌特效使用 GPT Image 生成的透明金色素材，服务端确认后短暂播放，自动避开牌面，遵循系统减少动态效果设置。

大厅和牌局分别使用用户提供的 `微乐麻将BGM.zip` 中对应录音；导入时统一音量，首尾各做 30ms 淡入淡出。场景切换清除旧播放任务并淡出旧曲，缓存解码结果；前后台恢复沿用现有音频生命周期，不叠播。

超时后自动托管以及持续到下一把的托管均可取消；接手时恢复当前手动操作时限，重复取消不延长时限。

首页实时牌桌不再截取两桌，按空位与开局状态排列所有未结束牌桌；列表可上下滑动，标题和底部导航保持可见。
