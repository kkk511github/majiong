# 金陵麻将规则核查与外包案例

日期：2026-09-20。范围：当前进园子B档，以及本轮用户最终确认的“必须头三嘴同一家，第四嘴来自任何人”和快照提示统一“胡”。这里说明原始积分，不是最终日结除以2后的数值。

## 先分清三件事

- **牌型**：实际牌面组成，例如对对胡、清一色、真正四组落地的全球独钓。
- **快照**：特定关系下允许提前成胡，余下两张可以不是对子；计分会构造第四组，但不会替你真的执行一次碰牌。
- **外包**：合法胡牌后由谁付分、记桌内还是桌外。外包并不意味着任何牌都能直接胡。

用户确认的快照，第四嘴不限制供牌人；所有快照结束提示、结算标题、战绩标题与回放均显示“胡”。明细将其专门的50分项目标为“快照加分”，保留参考牌分，同时突出实际外包收款。

## 一、头三嘴责任的排列（按用户最终口径）

以下是胡牌者已经实际完成的四组碰杠，各字表示这组是谁供牌。

| 四组来源 | 三嘴外包判断 |
|---|---|
| 甲、甲、甲、乙 | 甲已供三嘴，由甲承担 |
| 甲、甲、乙、甲 | 不成立甲的三嘴外包，头三嘴已经夹了乙 |
| 甲、乙、甲、甲 | 不成立甲的三嘴外包 |
| 乙、甲、甲、甲 | 不成立甲的三嘴外包，不能取后面连续三嘴 |
| 甲、甲、乙、乙 | 两人都只有两嘴，不单凭三嘴规则指定付款人 |
| 甲、乙、丙、甲 | 甲两嘴，不构成甲三嘴 |

用户最终明确保留原规则：必须头三嘴同一家，夹开不能累计凑三嘴。临时累计实现已撤回，未部署到生产。对对胡、全球等合法胡牌后，已成立的三嘴责任人付桌外普通50分、比下胡100分，不再同时扣一份普通胡牌分。

暗杠仍沿用原先计嘴规则，至少一嘴需要实际外部供牌；三个暗杠不会凭空产生责任人。“甲、乙、暗杠、暗杠”的头三嘴已有甲乙两家，不成立三嘴；不存在用第四嘴反推责任人的情况。

## 二、快照的所有主要情况

| 当时的状态 | 当前处理 |
|---|---|
| 已经形成甲的三嘴，甲再打出能凑第四刻的牌 | 可直接选“胡”，甲承担外包 |
| 已经形成甲的三嘴，乙/丙/丁打出能凑第四刻的牌 | 同样可直接选“胡”，仍由甲承担外包 |
| 三组三清明牌，本次同花色弃牌能凑第四刻，无优先三嘴责任 | 可三清快照，由本次出牌者承担外包 |
| 三嘴和三清同时成立 | 三嘴责任优先，只结一份外包 |
| 前三组尚无三嘴关系，且不满足三清 | 不能仅因计分副本能拼第四组就获得快照资格；仍要满足普通成胡结构 |
| 同一弃牌同时可以普通胡与快照胡 | 当前在合法候选中取高分，可能选快照；这不等于实牌有四组副露 |
| 凑成的是顺子而不是同张三张 | 不能以第四碰触发快照 |
| 自摸、抢杠 | 不使用快照特殊成法；各走本身的合法成胡与付款规则 |
| 响应时先选了“碰” | 先完成碰牌与出牌流程，不补发刚才那次快照胡按钮 |
| 没选择胡或不满足成胡条件 | 不收这次胡牌外包 |

**甲甲乙不会被第四嘴补救**：这三组没有三嘴关系，甲再出第四嘴也不开放三嘴快照。若本来满足普通成胡或三清快照，则按相应分支处理。

## 三、全球独钓与黄色架牌

| 情况 | 全球独钓牌型 | 黄色架牌/该项外包 |
|---|---|---|
| 真实四组碰杠已完成，胡前一张，胡后成对子 | 成立 | 还要单独判断架牌条件 |
| 三碰后暗杠第四组，补牌再打牌只留一张 | 成立 | 不建立第四碰黄色架牌 |
| 三碰后直杠第四组，再补牌出牌只留一张 | 成立 | 不建立第四碰黄色架牌 |
| 前三组均明碰，第四组实际明碰，随后出牌留单张 | 成立 | 刚打出的那张实体牌变黄 |
| 架6条，仍听5条，别人打5条且实际胡 | 成立 | 同花色±2范围内，放炮者外包（无更优先责任时） |
| 架6条，仍听5万，别人打5万且胡 | 成立 | 花色不同，不触发6条架牌的外包 |
| 架6条，其他人打4～8条，但本人不能胡或选择过 | 尚无本次胡牌 | 不收费，不禁止他人出牌 |
| 主动换听，后来又换回 | 仍可按最终合法牌型胡 | 原黄色和原架牌责任永久取消 |
| 摸到同种另一张、仍留相同牌种单钓 | 不改变听口 | 原架牌保留 |
| 只有快照计算中的虚拟第四组 | 不算普通真实全球状态 | 不生成黄色架牌；结束提示“胡” |

数牌范围同花色前后两张、包括本身，1/9不循环；风牌沿当前口径四风互相覆盖。黄色本身只提示风险。全球自摸不收黄色架牌外包；若本来有三嘴责任，仍可能由三嘴责任人承担。三嘴优先于三清，三清优先于架牌外包，不对同一胡者重复收多项外包。

胡张出牌者桌内0分时不能被胡；这与外包责任人余额是否为0是两个问题。出牌者有分、三嘴责任人已0分，仍可能向责任人记桌外外包。

## 四、498046第三局的具体结果

秦淮三组实牌是北风直杠、九万碰、三筒碰，均来自钟山；手里七万七万八万八万。莫愁打八万后：

- 普通候选：对对胡，(10+30+6+6)×2＝104。
- 用户已确认“第四嘴任何人”口径下，快照候选：(10+30+50+6+6)×2＝204。
- 原来标题把计分中的全球档画成了普通“全球独钓”，现改为“胡”，明细用“快照加分”解释50。
- 实际只结三口外包：钟山付秦淮100分，未按204扣。
- 原始数据和已结算金额不改写。

## 五、当前全部主要牌型分值与条件

下表是普通局的单项加分。除天胡外，成牌10、可叠加牌型、硬花×2、软花×2及听口分先相加，最后乘本把倍率。分数不是自动等于实收，实际收付还受外包、余额与保米影响。

七对四档只取一档，不叠门清、对对胡；可以叠符合条件的清/混一色、无花果等。不能把不同拆解的牌型混加；多个合法拆解取最高分。普通开门小胡有1～3硬花不能胡，软花不能凑门槛；0硬花则另按本项目无花果口径。

抢杠没有独立固定加分；按实际胡者的一份S，由尝试补杠者向其余三家各付一份。用户确认的例子：成牌10＋压绝30＋四硬花8＝48，各家收48，被抢者共付144；比下胡则各96。多人抢杠按各位实际胡者分别计算，收钱的旁家不因此标成胡牌。

暗杠即时每家5、直杠/补杠对应供牌者10、花杠每家10；比下胡分别10、20、20。胡牌软花另算，不把即时杠费重复加进S。天胡400、桌外固定50/100属于各自例外，不重复翻倍。

## 六、核查结果与需要继续定口径的边界

已确定并处理：

1. 快照显示误导：提示统一“胡”，明细分开参考牌分与外包实际收款。
2. 头三嘴规则重新确认：原实现正确；累计变体已全部撤回，并补充头三嘴及第四嘴任意供牌的回归。
3. 主规则文档的压绝范围/免花、抢杠收款说明过时：按已确认代码更新。
4. 海底现已确认并改为最后一张：摸前1张、摸后0张且自摸成胡才加20，倒数第2～5张不计，末张弃牌被点胡不计。

普通基础牌型37项独立正反例、既有533条实体样例重算均通过。特殊事件6套280项回归通过；临时累计方案已撤回，原计分函数恢复，并单独重测最终头三嘴规则。这些证据支持所检查的条件，不等于宣称所有地方玩法都一样或游戏已经数学上无任何缺陷。

仍未擅自选择：

- 地胡普通弃牌主动把两个听口缩为一个，当前仍保留地胡；是否要求严格摸什么打什么、只在杠后允许缩听。
