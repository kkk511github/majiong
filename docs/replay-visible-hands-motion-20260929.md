# 回放明牌与摸牌、插牌动画

2026-09-29。接续回放首帧等待及战绩输入修复，仅修改本地回放表现和共享渲染器。未部署网页、未同步原生工程、未打包/上传 APK 或 IPA，原 Build89 不变。

## 明牌

- 用户确认指的是其他三家的手牌牌面，而不是昵称标牌。
- 回放原本已有“四家明牌”数据与模型路径，但全宽不透明顶栏覆盖了对家的牌面。改为透明悬浮顶栏，仅角落按钮保留底色；用户已确认顶栏可以透明。
- 对四个观看视角分别验证四家实际牌面模型；切回“当前视角”时，另外三家的暗手继续隐藏。实时对局的服务端手牌隐私不变。

## 摸牌与插牌

- 原 `prepareMotion` 明确排除回放的手牌移动，只允许回放动作特效，因此连续播放没有摸牌/插牌过程。
- 新增明确的回放播放状态、明牌模式及倍速；仅在同一回放、同一视角/明牌模式下连续前进时移动手牌，保留同帧重绘中的在途动画。暂停、跳步、后退、切视角、重新加载不补播历史移动。
- 原回放只追踪当前视角的摸牌，其他三家按全手排序会把最大牌误放在额外摸牌槽。现在从已保存的事件识别各家实际摸牌，先留在摸牌位置，打出另一张牌后再插入排序位置。
- 四家的插牌使用实际物理牌标识，摸什么打什么不插牌；起手第十四张没有明确摸牌事件时不猜测。隐藏手牌时不向渲染状态提供摸牌身份。
- 动画时长跟随回放倍速；联机对局的原有时长和规则不变。

- `npm test`：包括回放手牌身份保持、隐藏模式、四家插牌及开局不伪造摸牌测试。
- `playwright test -c playwright.replay-input.config.ts`：Chrome/WebKit，包含明牌模式与四视角、1×/4× 实际摸牌/插牌位移、暂停/跳转、上一批首帧和输入回归，以及实时牌桌动作回归。
- 动画测试观察实际渲染帧中的中间进度与坐标变化，不以“存在动画对象”代替实际移动。早期 35ms 定时采样落在 WebKit 首次 tween 更新之前，已改为逐帧采样。
