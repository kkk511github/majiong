# 0.5.6 原生验收与修正

2026-09-14，build 16。本轮 Mac 解锁后恢复原生操作，旧锁屏限制已解除。

## 已修复

- 横屏注册：旧版滚动区只露出后一排输入，系统键盘的“上一项”不能顺畅回到账号。新版键盘弹出时，账号、昵称、密码、确认密码两列两行同屏，提交按钮在右侧，输入和按钮保持 44 像素高度。实际操作上一项、空表单校验、收起键盘通过。
- 横屏结算：iOS WebView 中第四名被裁切。压缩结算行、头像及装饰间距后，四名玩家、时间/房间信息、记分倍率、复制与继续按钮可见。874×402 原生测量：四行各 36px，第四行底部 253px，滚动容器底部 313px。

## 验证

131 项逻辑/服务、109 项界面检查全部通过。键盘检查覆盖 568×320、844×390、874×402 的登录/注册，在 120px 可视区逐个验证所有输入与按钮；房号键盘用例保留。

独立 QA App 中检查真实 AudioContext 目的节点信号：仅音效开启时按钮点击有信号；全部关闭后同按钮无信号；音乐开启持续有信号。切至 Springboard 约 44 秒再返回，记录 hidden/suspended → visible/running，未再触摸网页即可恢复音乐，只有一个音频上下文。探针只读分析输出，不调用播放或强制恢复。未把系统回到前台写成真实来电中断测试，也未把电平写成用户听感确认。

正式 build 16 已在 iPhone 17 Pro 模拟器安装并实际查看首页：保留 kkkk 普通账号，不显示开桌入口；没有修改该账号声音偏好。独立 QA App 已移除，正式两端资源不含探针。物理 iPhone 当前 unavailable，未安装本版到真机。

Android APK 已构建并核验既有签名和包内资源；本机模拟器启动停在 adb 注册之前，因此本版 Android 原生键盘/触摸未通过验收，不能以浏览器测试代替。
