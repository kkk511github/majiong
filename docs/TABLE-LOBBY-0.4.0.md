# 0.4.0 建桌大厅与对局设置

2026-09-13。入口：底部「约局」→「开桌设置」。按用户选定的范围，本版完成设置、开空桌、选座加入、四人开局，以及准备、托管、续桌等对局设置。

## 使用流程

1. 玩法设置：填写名称，选择 4 / 8 / 12 / 16 局、每步 10–300 秒、结算展示 5 / 10 秒。
2. 桌子设置：一次开 1–5 桌，选择大厅公开或仅凭房号，自动或手动准备，并设置托管和续桌。
3. 确认开桌：创建空桌后返回大厅。开桌人也需点选空位入座；可以直接复制六位房间号给朋友。
4. 默认自动准备：满四位在线真人自动发牌。手动模式需要四人都准备；未满四人不发牌，大厅桌不允许电脑补位。
5. 一桌局数打完后，开启自动续桌会等待结算展示结束，将大家送回大厅，再以相同房号和设置续开空桌。关闭续桌则停止。开桌人可以收起未开局或已结束的桌子。

首页原来的「创建房间」保留为快速好友房，可手动准备和添加电脑；新建桌功能使用「约局」入口。

## 设置行为

| 设置 | 实际行为 |
| --- | --- |
| 准备方式 | 自动准备满四人即开；手动准备须逐人确认，每局结算后按同样方式继续 |
| 离线开局 | 默认要求全员在线；允许时由托管操作离线玩家 |
| 自动离座 | 第一局发牌前，离线或未准备超过 10–60 秒离座；不会在正在计分的牌局中替换玩家 |
| 整桌托管 | 超时后自动操作，可由本人取消 |
| 单局结束暂停 | 托管玩家本局结算后停止，必须本人点击继续；自动准备也不能绕过该暂停 |
| 超时结束本桌 | 出牌超时直接结束；结算仍保留 |
| 连续托管后结束 | 连续托管达到所选局数后结束本桌 |
| 关闭托管 | 不限制每步时间，不显示假倒计时；要求在线开局 |
| 结算展示 | 5 / 10 秒内不会发下一局，自动续桌也遵守展示时间 |
| 协商解散 | 开启后需四人同意；关闭时前后端都拒绝申请 |
| 昵称显示 | 可仅在大厅隐藏，或在牌桌和战绩中隐藏他人昵称 |
| 续桌 | 保留房号、设置和创建人，清空座位及本桌积分，前一桌战绩独立保留 |

大厅可按等待开局、我开的桌筛选，按房号或名称查找；座位和状态实时更新，重连会重新订阅。空大厅显示明确的开桌入口。

## 服务与数据

服务端统一执行设置、座位占用和开局门槛，客户端不能绕过。批量创建在同一数据库事务完成；同一个创建标识重试不会多开桌，失败不会留下半批桌子。加入同一空位的并发请求只接受一个。

新表 `table_creations` 存储创建幂等记录，`table_archives` 保留结束的完整桌次；原 `rooms` 保存活动桌和空桌。普通快速好友房继续按最近 24 小时恢复；建桌大厅的设置和空桌跨重启保留，不受 24 小时限制。创建人的身份仍依赖本机会话凭证（既有会话 30 天有效期）；本版没有跨设备账号管理。

大厅只发送四个座位的状态摘要，不发送暗手或牌墙。完整结算记录在重新登录时恢复到本机战绩，最多保留最近 100 局。
