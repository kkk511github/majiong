# 0.7.6 / build 42

## 本版改动

- 女声胡牌、自摸采用用户试听确认的 AI 女声“胡了”；男声采用用户上传的原录音。保持其他南京话报牌片段。
- 听牌提示采用手牌上方长条：展示全部可胡牌面与各自剩余张数；候选舍牌标记金色箭头，首次点击看听口，再点同一张确认出牌；无听口时隐藏提示。
- 自摸/胡使用手牌上方金色字效，点炮人的头像附近显示“点炮”；胡牌事件播对应语音，重连不重播旧结果。
- 修复预览父页面与牌桌切换焦点导致胡牌漏播；增加声音恢复、试听实际播放反馈，保留静音和音量选择。
- 纳入管理员独立已读/未读筛选、会员ID查询与返回列表位置保留、战绩摘要导出、结算计分详情及回放关键步骤跳转。
- 纳入网络阶段、延迟与同步提示、有限退避重连、恢复期间禁止发送旧操作、声音/网络诊断及按需页面加载。

## 安装包

- Android：`金陵麻将-0.7.6-build42.apk`，沿用现有正式签名，可覆盖相同签名旧版。
- iOS：`金陵麻将-0.7.6-build42-AdHoc.ipa`，沿用现有 Ad Hoc 签名，只能安装至描述文件内已登记设备。
- 两包内217个网页资源逐字节一致；男女声录音、发行签名、版本号、关闭调试、证书绑定及不包含源码映射检查通过。
- 本次构建来自当前工作区的固定源码快照；没有新建代码提交。完整快照摘要和安装包哈希记录于验收文件。
