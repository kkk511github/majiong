# 六筒、九筒牌面重设计 v3

日期：2026-09-16。以下为设计稿与实现目标；当前 APK/IPA 及运行中的牌图尚未替换。

## 查证结果

六筒常见中式排列为两列三行，上面两颗绿圈，下面四颗红圈；绿圈与红圈之间有分组间距。九筒为三行三列，各行同色，中间为红色，上下为深色与绿色。深色使用蓝色或近黑色，以及上下朝向，在不同牌具中存在差异。本项目沿用已有中式牌组的黑、红、绿配色。

参考：
- [筒子图例：Mahjong Odyssey](https://www.mahjongodyssey.com/tiles/circles)
- [Mahjong tiles — Circles](https://en.wikipedia.org/wiki/Mahjong_tiles#Circles)
- [麻雀牌](https://zh.wikipedia.org/wiki/麻雀牌)

## 比例与排列

以去掉倒角、牌背和厚度后的白色正面为测量基准；宽为 W，高为 H，H/W = 1.38。坐标原点为正面左上角。生成图用于确认材质与风格，实施时按这些坐标精确排布，而不是拉伸整张生成图。

| 参数 | 六筒 | 九筒 |
|---|---|---|
| 圆圈排列 | 2 列 × 3 行 | 3 列 × 3 行 |
| 从上到下颜色 | 绿绿 / 红红 / 红红 | 黑黑黑 / 红红红 / 绿绿绿 |
| 单圈外径 | 0.27W | 0.22W |
| 横向圆心 | 0.29W、0.71W | 0.24W、0.50W、0.76W |
| 纵向圆心 | 0.23H、0.55H、0.77H | 0.22H、0.50H、0.78H |
| 图案外包框宽度 | 69% W | 74% W |
| 图案外包框高度 | 约 74% H | 约 72% H |
| 外包框上下留白 | 各约 13% H | 各约 14% H |

占比指整组图案外包框宽/高，并非着色面积。九筒的圈外径约为六筒的 81.5%，以容纳第三列；同一张牌上所有圈等大。六筒上方绿色一组与下方红色四圈之间的间距略大，整体外包框垂直居中。

## 色彩和质感

- 墨绿：#174C34；朱红：#B82B25；近黑：#242A27；暖白：#F3F0E5。这些是目标基础色，渲染光照会改变输出像素值。
- 牌体保持细腻树脂材质和柔和倒角，牌背为玉绿色。
- 同心圈采用浅刻填色，白色细线保留牌体材质；不做凸起圆片，不带彩色光晕。
- 牌面图案的轮廓要清楚，圈纹保持一致；缩小到弃牌尺寸后仍应能数出 6 个和 9 个圈。
- 正面母版不烘焙桌面方向；后续通过同一预渲染流程输出四家角度，安卓/iOS共享同一份资源。
