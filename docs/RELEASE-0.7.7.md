# 0.7.7 / build 43

## 改动

- 修复安装包战绩页无法打开：旧打包流程在模块文件名中的哈希占位符被替换前就混淆代码，导致实际点击战绩请求不存在的文件并返回 404。现在先输出最终文件，再混淆；对未解析占位符直接拒绝构建。加载失败提示不再一概归因于网络。
- 牌桌 iframe 恢复占满窗口；大厅、托管、牌局、记录、设置悬浮于牌桌两侧，移除会压缩牌桌的顶部栏及安全区外边距。安全区仅作用于按钮。
- 使用 imagegen 生成玉绿金边按钮底图，配合 Lucide 图标、中文标签和按下反馈；托管开关保持原有行为。
- 纳入战队积分修正：每桌每人桌费只扣一次，再除以该桌保存的积分除数；按实际牌桌计桌数，列名为“把数 / 桌数（8局/桌） / 积分”。示例牌桌的 5 把计 1 桌。
- 保留已确认的男女声胡牌、听牌长条、候选出牌预览、点炮者提示、管理员战绩已读、回放和网络/音频恢复功能。
