# 功能内部适配与 iOS 模拟器验收

## 边界

本轮继续现有界面主题适配，不更改规则、权限、邀请协议或牌桌渲染。新增 src/game-features.css 复用 game-ui 的 Token，补齐通用弹窗内部未覆盖的旧样式。个人页 profile-v3 是单独的讨论稿，尚未替换当前个人页布局。

## 清单

| 现有功能 | 本轮处理 | 验证依据 |
| --- | --- | --- |
| 在线牌友列表 | 房间信息、搜索、头像、邀请按钮、状态色 | 真实双端及状态夹具 |
| 邀请加载/空列表/搜索无结果/失败 | 独立状态区，失败不同时显示“暂无牌友” | features-adaptation |
| 发送中/忙碌/等待回应 | 禁用外观与等待状态区别，不改变原 pending 判定 | 防双击请求验证 |
| 收到邀请 | 邀请人、房号、规则、人数、准备说明、席位及固定底部操作 | 568×320 / 844×390 |
| 邀请过期/离线 | 保留原因，接受不可用，复制房号仍可用 | 过期显示时钟及浏览器offline |
| 公告、更新 | 内容区、列表、状态、进度、确认按钮使用同套主题 | 更新11种平台/错误/取消状态回归 |
| 战队会员管理 | 表单、查询、统计、列表与日期换行 | 分队、禁赛、改名、CSV、慢请求恢复 |
| 开桌权限 | 查询、空结果、角色标签；无新授权能力 | 三角色权限回归 |
| 战绩详情及导出 | 共享颜色，移除导出标题的旧 !important 覆盖 | 记录与明细浏览器回归 |
| 头像与声音设置 | 共享内层样式，保持原上传与持久化 | 头像上传/恢复与个人页回归 |
| 牌桌和回放牌面 | 不修改 | shared/server/cocos-table 无源码差异 |

邀请倒计时的60秒上限只是显示修正：渲染周期可能早于刚到的邀请，原先会短暂出现61秒。没有修改服务器 expiresAt，也没有延长邀请。

## 窄屏修复

- 管理页日期筛选必须换行，不能覆盖查询/CSV按钮。
- 最矮横屏缩小非功能外边距，保留积分滚动区和固定分页。
- 中等横屏战绩卡片高度精简，首屏完整显示三桌，不减少数据。
- 受邀弹窗优先显示准备说明，席位预览可在内容区滚动，底部拒绝/接受始终保留。

## 模拟器

设备：iPhone 17 Pro，iOS 26.5。
演示应用标识：com.jinling.mahjong.demo，与正式应用分离。
使用项目现有 Capacitor 原生壳构建；不是全 Cocos 原生迁移完成声明。

- 前端：本机5181端口（专门的原生演示配置）。
- API：同源代理到本机8791端口，复用隔离管理员演示数据库。
- 不连接线上服务器；没有放宽服务端CORS。
- 构建时临时生成的Capacitor配置已恢复原内容，原生源码/项目配置没有提交差异。
- xcodebuild模拟器构建、安装、启动成功，已目视确认原生窗口载入本地界面。

用户正在操作模拟器时不再自动切换页面。网页的管理员演示仍在5179端口。
