## 分层与状态

- 按钮：接触阴影、玉牌底板、主字、少量杠刻痕/胡朱砂点、待确认标记分别组织；阴影和底板/主字同步按压。过使用同底板的灰绿材质处理。
- 确认特效：独立Cocos Sprite主字、两段短笔势/杠底笔势/胡弧势、玩家及已确认标签。不是按钮点击后直接播放。
- 扣分：按最新反馈取消绿色底板、边框及面板阴影，改用大金额、朱砂负号、小玩家名与原因。原始金额、原因和付款座位来自既有确认流水。
- 默认/按压/待确认/禁用状态在ActionButtons中管理；不存在于合法动作集合里的选择不渲染。待确认不是“动作已成立”。

## 最新位置和时序（后续用户反馈优先于初始概念）

- 碰、杠：各家固定弃牌区域的中心，由现有牌桌布局推导，不随当前弃牌张数跳动。碰约1200ms，杠约1450ms，放大出现、停留、缩小淡出。
- 胡：保留手牌中线锚点及约1120ms时序；所有文字面向屏幕，按真实获胜座位分别呈现。
- 杠类扣分：收到对应Cocos播放完成回执后开始展示；故障时有限超时放行，不能无限等待。独立弃牌罚分无需等待无关动作。只延后提示，不延后计分或回合状态。
- 配置集中在`shared/action-presentation.ts`，锚点在`shared/action-anchors.ts`。所有临时运动回到布局给出的终点，不写入牌局数据。
