# 结算表输出

`templates/` 保留审核过的原始样式参考。`workbook.ts` 每次生成时移除参考模板中的「20分数」「20金额」，将「50积分」改为「50金额」，输出固定六列：战队名、玩家ID、昵称、50分数（日结）或50局数（周结）、50金额、总结算。

日结、周结的新文件显示账号当前昵称（`accounts.name`），不再把登录账号当昵称；仅遇到昵称缺失或空白的历史数据时回退到账号名。玩家ID保留，重名也不会合并；昵称按文本写入，公式样式的昵称不能成为可执行公式。已冻结/已发送的历史文件不改写。

日结金额仍为分数÷2，周结金额仍为局数×3。总结算引用金额，底部总计对三列数值分别求和。标题合并、筛选和打印区域均以 F 列为界。历史已保存的发送快照继续原样重发，不重建文件。

新生成的日结表按「50金额」数值从高到低排序（正数、零、负数；不是绝对值），金额相同时按玩家ID数值升序。排序覆盖整张合并战队日报，玩家整行及其公式一起生成，总计始终在最底部。周报保留原来的行顺序，输入数据和数据库不被排序操作修改。

回归测试：`tests/report-xlsx.test.ts` 验证真实 XLSX 的六列、公式与缓存、总计、空报表、安全文本、格式以及跨日重试时的文件字节一致性。
