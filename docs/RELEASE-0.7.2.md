# 0.7.2 / build 38

## 改动

- 全新胡牌/听牌卡片：象牙白与翡翠绿双栏布局，听口大牌面，拟打出牌预览，多听口横滑；从公开信息计算未见数，明确含他人暗手，绝不使用暗牌估算牌墙。
- 可胡与自摸单独展示，使用内置 ImageGen 生成的透明翡翠金边“胡”徽章。设计原图、完整提示词及实际素材见 `IMAGEGEN-0.7.2.md`。
- 全球独钓架牌、改支；报照直、权限校验、禁对对胡/快照、三嘴后禁杠；声明记入回放。非法胡牌继续由系统拒绝。
- 三嘴前三嘴、三清快照、普通顺子不收三嘴外包、杠后补花计花开保留责任、海底比下胡及三嘴后暗杠免收现场费。
- 延续0.7.1的鲜艳立体牌面、管理员按账号已读勾选、安卓/iOS键盘避让；本次补齐统一牌面裁切及布局读取真实视角比例。

## 验证

全量单元测试32个文件、305项通过；真实牌桌加新提示组件在Chrome/WebKit共12个场景通过，覆盖568/844/1280宽度；另补测无听口不能显示“打出后可听”。安装包签名及哈希见交付目录的验收JSON。测试中发现的568小屏照直确认被提示卡挡住已修复，并在Chrome/WebKit复测。俱乐部测试改用明确的出牌事件等待，避免固定50ms等待及牌被电脑碰走后误报未出牌。
