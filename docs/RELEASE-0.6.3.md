# 0.6.3 / build 23

- 迁移到独立服务器，使用受信任的公网 IP HTTPS 证书与自动续期。
- 保留原生正式签名、R8、禁用调试及备份，新增 JavaScript 混淆和 TLS 公钥固定。
- 新增首次主动同意的用户协议及隐私说明，明确娱乐用途和禁止赌博。
- 完整全屏牌局回放、四家视角、明牌、倍速与进度拖动；旧局仅有结算时如实标注。
- 弃牌标记根据四家方向和排间空位调整，带不遮挡牌面的轻微动效。

验证：170 项规则与服务端测试、28 项界面测试通过；迁移演练验证四个 HTTPS/WSS 客户端、断线恢复、结束回放、积分与 CSV 导出。最终数据库从旧服停机后的快照复制，演练数据不带入正式库。

iOS 为 Apple Distribution Ad Hoc 签名，仅限描述文件登记设备；不是 App Store 任意设备分发包。Android 为已有正式密钥签名，可覆盖同签名旧版本。加固不能保证绝对不可逆向。
