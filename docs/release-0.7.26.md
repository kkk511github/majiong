# 金陵麻将 0.7.26 / build 63

牌桌新增南京话快捷短句，并调整语音入口和中央风位。

- “短句”和“语音”移到右侧头像下方，与托管等顶部按钮分开；小屏横屏切换为横排，尊重刘海安全区。
- 使用用户提供的南京话包，导入12条短句的男女声共24段原始MP3。点击短句后由服务器确认并发给同桌成员，发送成功收起列表，发言者门前短暂显示文字气泡。接收方跟随现有男女声和同桌语音设置；真人语音优先，短句不积压。
- 短句仅接受固定编号。独立确认不锁住打牌操作，限制连续发送；断线、换桌清理，消息不持久化，不在重连后重播。
- 东南西北分成四块。对应最近出牌者的一侧亮起，牌被碰走后保留提示；新桌、新把、重连和回放跳转清理显示记忆。倒计时、余牌、余花和把数位置保持，风位节点复用。
- 原按住说话、松开发送、上滑取消保留。新的碰杠选择出现时收起短句列表，文字气泡不会抢占碰杠按钮的点击。

本次没有修改计分和游戏规则；两端安装包基于当前完整代码，包含此前已确认的规则修正。
